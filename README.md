# Devyani Thokal — Personal Portfolio

Modern, minimal portfolio website built with HTML, CSS, and vanilla JavaScript.

Live site: [devyanit05.github.io/personal-portfolio](https://devyanit05.github.io/personal-portfolio/)

## Tech stack

- HTML5
- CSS3 (custom properties, responsive layout)
- Vanilla JavaScript (no frameworks)

## Local preview

From the project root:

```bash
python -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173)

## Project structure

```
personal-portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   ├── certificates/
│   └── resume/
└── .github/workflows/deploy.yml
```

## Deployment

Pushes to `master` deploy automatically to GitHub Pages via GitHub Actions.
